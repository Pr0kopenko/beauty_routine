# Уход (CareTracker)

Простое iOS-приложение для трекинга ухода: когда наносила ретинол и сыворотки, пила ли магний и другие добавки.

## Что уже есть

- **Сегодня** — список средств; тап отмечает «сделала сегодня», повторный тап снимает отметку. Видно, когда средство использовалось в последний раз.
- **История** — все отметки по дням, свайп удаляет запись.
- **Средства** — добавление/удаление средств трёх типов: ретинол, сыворотка, добавка.

Данные хранятся локально на устройстве (SwiftData).

## Требования

- Xcode 16+
- iOS 17+

## Запуск

1. Открыть `CareTracker.xcodeproj` в Xcode.
2. Выбрать симулятор iPhone (или своё устройство — тогда в *Signing & Capabilities* указать свою команду).
3. ⌘R.
