# Ритм кожи

Личный трекер ухода за кожей: показывает, когда можно ретиналь, подсказывает, что с чем не сочетать, отмечает уход и магний и напоминает о них.

## Прототип (PWA) — пользоваться сейчас

**https://pr0kopenko.github.io/beauty_routine/**

1. Открой ссылку в Safari на iPhone.
2. «Поделиться» → «На экран „Домой“».
3. Открывай только с иконки: у вкладки Safari и у иконки разная память.
4. Напоминания: «Ещё → Напоминания → Добавить в Календарь».
5. Раз в неделю: «Ещё → Сохранить копию в Файлы». Данные лежат только на телефоне.

Код — в [`web/`](web/), тесты логики — `node --test web/tests/logic.test.mjs`, выкладка — `./deploy.sh` (ветка `gh-pages`).
