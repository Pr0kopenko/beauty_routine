# Сервер-посредник для друзей

Чтобы друзьям не заводить свой ключ Claude, поднимите этот Cloudflare Worker один раз (бесплатного тарифа хватает).

1. dash.cloudflare.com → Workers & Pages → Create → Worker → вставить `worker.js` → Deploy.
2. Settings → Variables: секрет `ANTHROPIC_API_KEY` (ваш ключ), переменная `INVITES` — коды через запятую, например `masha,olya`.
3. Для дневного лимита: Storage → KV → создать namespace, привязать к воркеру под именем `USAGE`. `DAILY_LIMIT` — по желанию (по умолчанию 40).
4. Другу: адрес воркера (`https://….workers.dev`) и его код. В приложении: Настройки → Распознавание → «Инвайт-код».

Сервер получает только фото упаковки и ничего не хранит, кроме счётчика запросов на код в сутки. Фото лица приложение в ИИ не отправляет.
