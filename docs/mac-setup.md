# Как начать разработку на своём Маке

## Что такое `CareTracker.xcodeproj`

Это файл проекта Xcode. Внутри — список исходников приложения и настройки сборки (название «Ритм кожи», иконка, iOS 17+, разрешения на камеру и Face ID). Код самого приложения лежит рядом, в папке `CareTracker/`. Открываешь этот файл двойным кликом — Xcode показывает проект и умеет собрать и поставить приложение на iPhone.

PWA (папка `web/`) — отдельный веб-прототип. Нативное приложение уже переписано на Swift и умеет импортировать данные из PWA.

## Шаг 1. Скачать репозиторий на Мак

Открой «Терминал» (Spotlight → «Терминал») и вставь:

```bash
cd ~/Documents
git clone https://github.com/Pr0kopenko/beauty_routine.git
cd beauty_routine
open CareTracker.xcodeproj
```

Если Мак попросит установить «инструменты командной строки» — согласись и повтори команду.

## Шаг 2. Первая сборка в симуляторе (без телефона)

1. В Xcode вверху посередине выбери устройство: любой iPhone из списка (например, iPhone 16 Pro).
2. Нажми ▶︎ (или ⌘R). Первая сборка идёт 1–3 минуты.
3. Откроется симулятор с экраном «Ритм кожи». Это и есть приложение.

Если Xcode просит скачать iOS-симулятор — согласись (Settings → Components).

## Шаг 3. Поставить на свой iPhone

1. Xcode → Settings → Accounts → «+» → Apple ID → войти.
2. Слева выбери синюю иконку проекта CareTracker → таргет CareTracker → вкладка **Signing & Capabilities** → Team: «(твоё имя) (Personal Team)».
3. Если появится ошибка про Bundle Identifier — замени `com.pr0kopenko.CareTracker` на что-то своё, например `com.vika.ritm`.
4. Подключи iPhone кабелем, на телефоне нажми «Доверять этому компьютеру».
5. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить → перезагрузить.
6. В Xcode вверху выбери свой iPhone и нажми ▶︎.
7. При первом запуске на iPhone: Настройки → Основные → VPN и управление устройством → твой Apple ID → «Доверять».

С бесплатным Apple ID приложение работает 7 дней. Потом снова подключи телефон и нажми ▶︎ — данные сохранятся.

## Шаг 4. Перенести данные из PWA

В веб-версии: «Ещё» → «Сохранить копию» → «Сохранить в Файлы». В приложении на экране приветствия: «У меня есть копия из веб-версии» → выбрать файл.

## Шаг 5. Чтобы Claude сам собирал и запускал приложение на твоём Маке

Сессия в облаке не видит твой Мак: она может менять код и проверять сборку в GitHub Actions, но не может нажать ▶︎ в твоём Xcode. Чтобы Claude работал прямо на Маке (сам собирал, запускал симулятор и смотрел ошибки):

- **Вариант А — приложение Claude для Mac.** Установи Claude Desktop (claude.ai/download), открой вкладку **Code**, выбери папку `~/Documents/beauty_routine` и работай там.
- **Вариант Б — терминал.**
  ```bash
  curl -fsSL https://claude.ai/install.sh | bash
  cd ~/Documents/beauty_routine
  claude
  ```
  Можно запустить `claude remote-control` в этой папке — тогда сессия на Маке появится в приложении Claude на телефоне.

Чтобы забирать изменения, которые Claude сделал в облаке: `git pull` в папке проекта, затем ▶︎ в Xcode.
