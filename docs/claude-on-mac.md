# Инструкция для Claude на Маке владелицы

Ты — Claude, запущенный локально на Маке владелицы проекта (Вика). Она дала полную автономию: всё делаешь сам — терминал, Xcode, браузер, настройки. От неё — только то, что по правилам может сделать лишь владелец аккаунта: пароли, коды двухфакторной защиты, нажатия на iPhone, вставка ключа OpenAI. Проси это коротко, по одному действию, и объясняй зачем. Общайся по-русски, без жаргона.

Проект: iOS-приложение «Ритм кожи» (SwiftUI, iOS 17+). Репозиторий: https://github.com/Pr0kopenko/beauty_routine (ветка `main`). ТЗ: https://claude.ai/code/artifact/c88ad6a8-ce30-49b7-8128-18de2ab5767f (раздел v4 сверху). Код ядра проверяется `swift test`, всё приложение — в GitHub Actions (сборка и скриншоты из симулятора).

## Цель
1. Приложение собирается на Маке и стоит на iPhone Вики и её мужа.
2. Распознавание по фото работает через сервер-посредник на Cloudflare с ключом OpenAI Вики. Бюджет — до $5 на двоих.
3. Приложение само переустанавливается раз в неделю: бесплатная подпись Apple живёт 7 дней.
4. Вика может вести разработку с телефона: эта сессия остаётся доступной через Remote Control.

## Шаги

### 1. Репозиторий
```bash
mkdir -p ~/Developer && cd ~/Developer
[ -d beauty_routine ] || git clone https://github.com/Pr0kopenko/beauty_routine.git
cd beauty_routine && git pull
```
Для пуша нужен доступ к GitHub. Если `gh` не залогинен: `brew install gh` (или скачай с cli.github.com), затем `gh auth login --web`. Код вводит Вика в браузере — открой его сам и покажи код.

### 2. Xcode и окружение
`scripts/mac-bootstrap.sh`. Скрипт:
- ставит Xcode из App Store, если его нет (ждать ~10 ГБ);
- переключает инструменты (нужен пароль Мака — попроси);
- принимает лицензию;
- качает симулятор и Node.js.

Проверка: `swift test` → все тесты зелёные; `ci/screens.sh` → скриншоты в `shots/` (посмотри их).

### 3. Apple ID в Xcode (один раз)
Открой Xcode → Settings → Accounts → «+» → Apple ID. Поле пароля и код 2FA заполняет Вика. Платный Apple Developer не нужен: хватит бесплатной Personal Team.

### 4. iPhone (один раз на каждый телефон)
1. Попроси подключить iPhone кабелем, разблокировать и нажать «Доверять этому компьютеру».
2. На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить → перезагрузка → «Включить».
3. Запусти `scripts/install-iphone.sh`. Если bundle id занят — `BUNDLE_ID=com.<что-то-уникальное>.ritm scripts/install-iphone.sh`.
4. При первом запуске на iPhone: Настройки → Основные → VPN и управление устройством → Apple ID → «Доверять».
5. Беспроводная установка: в Xcode → Window → Devices and Simulators → отметить «Connect via network». Потом кабель не нужен, если телефон в той же Wi-Fi.
6. То же для iPhone мужа.

### 5. Сервер распознавания (Cloudflare, бесплатно)
1. Аккаунт Cloudflare. Если его нет — открой https://dash.cloudflare.com/sign-up в браузере и заполни сам. Почту и пароль вводит Вика; удобно «Sign up with Google».
2. `scripts/deploy-proxy.sh`. Скрипт:
   - откроет браузер для `wrangler login` — Вика жмёт Allow;
   - попросит ключ OpenAI (`sk-…`) — его вставляет Вика, ключ остаётся только в Cloudflare;
   - напечатает адрес сервера и два инвайт-кода.
3. Проверь: `curl <адрес>` должен ответить `{"ok":true,…,"openai":true}`.
4. Проверь из России. Если телефоны в России, открой адрес сервера в Safari на iPhone без VPN — должен показаться тот же JSON. Если не открывается, перенеси сервер на другой хостинг или свой домен. Расскажи Вике, что выбрал и почему.
5. Лимит расходов: в https://platform.openai.com/settings/organization/limits поставь месячный лимит $5 (Вика подтверждает). Модель — `gpt-4.1-mini`.
6. На каждом телефоне в приложении: Настройки → Распознавание → «Инвайт-код» → адрес сервера + свой код → «Сохранить и проверить». Если у тебя есть управление экраном iPhone (iPhone Mirroring), сделай это сам; иначе продиктуй Вике.

### 6. Еженедельная переустановка
`scripts/weekly-reinstall.sh` ставит задачу launchd: каждое воскресенье в 12:00 — `git pull` и установка на iPhone в той же Wi-Fi. Предупреди Вику: Мак должен быть включён (можно в режиме сна с «Power Nap»), iPhone — дома.

### 7. Перенос данных из веб-версии
В PWA (https://pr0kopenko.github.io/beauty_routine/): «Ещё» → «Сохранить копию» → в «Файлы». В приложении: экран приветствия → «У меня есть копия из веб-версии». Если у Вики там ничего важного нет — пропусти.

### 8. Работа с телефона
Запусти в папке проекта `claude remote-control`, чтобы Вика могла писать тебе из приложения Claude на телефоне. Мак при этом не выключается.

Дальше разработка идёт так:
1. правки в `main`;
2. `swift test`, `ci/screens.sh`;
3. установка на iPhone через `scripts/install-iphone.sh`;
4. короткий отчёт Вике со скриншотами.

## Чего не делать
- Не вводи и не храни пароли Вики сам. Не отправляй ключ OpenAI никуда, кроме `wrangler secret put`.
- Не покупай ничего без явного «да» Вики: платный Apple Developer ($99 в год) нужен только для TestFlight и друзей. Из России оплатить его может не получиться.
- Не публикуй ключи в репозиторий.
