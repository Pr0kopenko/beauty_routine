# Инструкция для Claude на Маке владелицы

Ты — Claude, запущенный локально на Маке владелицы проекта (Вика). Она дала полную автономию: всё делаешь сам — терминал, Xcode, браузер, настройки. От неё — только то, что по правилам может сделать лишь владелец аккаунта: пароли, коды двухфакторной защиты, нажатия на iPhone, вставка ключа OpenAI. Проси это коротко, по одному действию, и объясняй зачем. Общайся по-русски, без жаргона.

Проект: iOS-приложение «Ритм кожи» (SwiftUI, iOS 17+). Репозиторий: https://github.com/Pr0kopenko/beauty_routine (ветка `main`). ТЗ: https://claude.ai/code/artifact/c88ad6a8-ce30-49b7-8128-18de2ab5767f (раздел v4 сверху). Код ядра проверяется `swift test`, всё приложение — в GitHub Actions (сборка и скриншоты из симулятора).

## Цель
1. Приложение собирается на Маке и стоит на iPhone Вики и её мужа.
2. Распознавание: офлайн в приложении + кнопка «Спросить ChatGPT / Claude» + пакетно через тебя на подписке Claude Max. Без API-ключей и сервера.
3. Приложение само переустанавливается раз в неделю: бесплатная подпись Apple живёт 7 дней.
4. Вика может вести разработку с телефона: эта сессия остаётся доступной через Remote Control.

## Шаги

### 1. Репозиторий
```bash
mkdir -p ~/Developer && cd ~/Developer
[ -d beauty_routine ] || git clone https://github.com/Pr0kopenko/beauty_routine.git
cd beauty_routine && git pull
```
Для пуша нужен доступ к GitHub. Если `gh` не залогинен: `brew install gh` (или скачай с cli.github.com), затем `gh auth login --web`. Код вводит Вика в браузере — открой его сам и покажи код.

### 2. Xcode и окружение
`scripts/mac-bootstrap.sh`. Скрипт:
- ставит Xcode из App Store, если его нет (ждать ~10 ГБ);
- переключает инструменты (нужен пароль Мака — попроси);
- принимает лицензию;
- качает симулятор и Node.js.

Проверка: `swift test` → все тесты зелёные; `ci/screens.sh` → скриншоты в `shots/` (посмотри их).

### 3. Apple ID в Xcode (один раз)
Открой Xcode → Settings → Accounts → «+» → Apple ID. Поле пароля и код 2FA заполняет Вика. Платный Apple Developer не нужен: хватит бесплатной Personal Team.

### 4. iPhone (один раз на каждый телефон)
1. Попроси подключить iPhone кабелем, разблокировать и нажать «Доверять этому компьютеру».
2. На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить → перезагрузка → «Включить».
3. Запусти `scripts/install-iphone.sh`. Если bundle id занят — `BUNDLE_ID=com.<что-то-уникальное>.ritm scripts/install-iphone.sh`.
4. При первом запуске на iPhone: Настройки → Основные → VPN и управление устройством → Apple ID → «Доверять».
5. Беспроводная установка: в Xcode → Window → Devices and Simulators → отметить «Connect via network». Потом кабель не нужен, если телефон в той же Wi-Fi.
6. То же для iPhone мужа.

### 5. Распознавание средств — через подписки владелицы, без API и сервера
**Обновлено 18.10.** У Вики нет API-ключей. Есть подписки Claude Max и ChatGPT/Codex, и она в России. Сервер на Cloudflare и ключ OpenAI **не нужны — пропусти** (`scripts/deploy-proxy.sh` не запускай).

Нельзя: вставлять логин или токены подписок Claude/ChatGPT/Codex в приложение или на сервер. Это запрещено правилами и грозит блокировкой её аккаунтов.

Как распознаём:
1. **Офлайн в приложении** (уже работает): фото состава → активы и концентрация по локальной базе.
2. **Кнопка «Спросить ChatGPT / Claude» в приложении.** Фото и готовый вопрос уходят в официальное приложение ChatGPT или Claude на iPhone, ответ вставляется обратно.
3. **Пакетно через тебя (главный путь для старта).** Работаешь на подписке Вики, это её личное использование.
   - Создай папку `~/Library/Mobile Documents/com~apple~CloudDocs/Ритм кожи/Фото` (iCloud Drive → «Ритм кожи» → «Фото»). Скажи Вике сфотографировать все средства, включая составы и вкладыши, и сложить фото туда из «Файлов» на iPhone.
   - Для каждого средства посмотри фото (ты умеешь читать изображения) и распознай бренд, название, активы, концентрацию, состав.
   - Найди в интернете инструкцию производителя. Принимай только страницу, где заголовок совпадает с продуктом: был случай, когда официальная ссылка на ретинол открывала азелаиновую кислоту. Нужна дословная цитата и ссылка. Предпочитай сайт бренда или два совпадающих магазина. У российских брендов схем в сети обычно нет — ищи на фото вкладыша.
   - Запиши всё в `iCloud Drive/Ритм кожи/карточки.json` в формате пакета: `{"app": "ritm-kozhi-pack", "products": [ ... ]}`. Каждый продукт — объект с полями из `Recognition.schema` (`CareTracker/Core/Recognition.swift`) плюс `intro_url`. Если схему не нашёл — `intro_source: "none"`, приложение честно покажет «схема не найдена».
   - В приложении: Средства → «Импорт карточек» → выбрать файл → проверить → добавить.
   - Если в приложении ещё нет «Импорта карточек» (его доделывает облачная сессия) — сделай `git pull`.

Проверка из России: приложение ChatGPT и Claude на iPhone у Вики работают (подписки активны), так что кнопка «Спросить» тоже будет работать.

### 6. Автообновление на iPhone
Запусти `scripts/auto-update.sh --install`. Задача launchd каждые 10 минут смотрит GitHub. Если в `main` появились правки (их делает облачная сессия по просьбам Вики), она забирает их и ставит приложение на оба iPhone в той же Wi-Fi. Раз в 6 дней переустанавливает в любом случае: бесплатная подпись живёт 7 дней. Старую задачу `weekly-reinstall` скрипт отключает сам.

Предупреди Вику: Мак должен быть включён (сон подходит, крышку можно закрыть при питании), телефоны — дома в той же Wi-Fi. Лог: `/tmp/ritm-auto-update.log`.

### 7. Перенос данных из веб-версии
В PWA (https://pr0kopenko.github.io/beauty_routine/): «Ещё» → «Сохранить копию» → в «Файлы». В приложении: экран приветствия → «У меня есть копия из веб-версии». Если у Вики там ничего важного нет — пропусти.

### 8. Работа с телефона
Запусти в папке проекта `claude remote-control`, чтобы Вика могла писать тебе из приложения Claude на телефоне, а облачная сессия проекта — присылать тебе задачи (например, «проверь установку»). Мак при этом не выключается. Основной канал обновлений — автообновление из шага 6, оно работает и без тебя.

Дальше разработка идёт так:
1. правки в `main`;
2. `swift test`, `ci/screens.sh`;
3. установка на iPhone через `scripts/install-iphone.sh`;
4. короткий отчёт Вике со скриншотами.

## Чего не делать
- Не вводи и не храни пароли Вики сам. Не подключай её подписки Claude/ChatGPT/Codex к приложению или серверу.
- Не покупай ничего без явного «да» Вики: платный Apple Developer ($99 в год) нужен только для TestFlight и друзей. Из России оплатить его может не получиться.
- Не публикуй ключи в репозиторий.
